# Full Stack - CRUD

A full-stack CRUD application built with:

## Frontend
- Quasar Framework
- Vue 3
- TypeScript
- Axios

## Backend
- NestJS
- Sequelize ORM
- PostgreSQL

## Features
- Create Task
- Read Tasks
- Update Task
- Delete Task

## Database

```bash
CREATE DATABASE taskdb;
```

## Run Frontend

```bash
cd frontend
npm install
npm run start:dev
```

## Run Backend

```bash
cd backend
npm install
npm run start:dev
```
